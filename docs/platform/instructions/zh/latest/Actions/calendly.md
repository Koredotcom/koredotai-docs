**Descripción general**

La plataforma Kore.ai XO le permite conectar fácilmente su instancia de Calendly para encontrar respuestas a sus consultas generales.

</container>

<container>

**Autorización**

Para conectarse a Calendly, Kore.ai utiliza autenticación básica. El usuario final puede usar credenciales preautorizadas proporcionadas por el desarrollador durante el proceso de configuración o su propio perfil de autorización durante el proceso de configuración para permitir que el usuario final se autorice durante la conversación.


 |Tipo de autorización                    | Basic |
 |----------------------------------------|-------|
 |Preautorizar la integración             |  Sí   |
 |Permitir a los usuarios autorizar la integración|  Sí   |


**Preautorizar la integración**

 Para facilitar el proceso de integración a los clientes, puede preautorizarla proporcionando las credenciales de autorización necesarias para obtener el token de acceso.

**Basic**

1. Por determinar

**Permitir a los usuarios autorizar la integración**

Este método requiere que el usuario final proporcione las credenciales durante la conversación para la autorización.

**Basic**

1. Seleccione Todos los usuarios para autorizar la integración.

2. Haga clic en Seleccionar autorización.

3. Seleccione Crear nuevo.

4. Seleccione el tipo de mecanismo de autorización.

   i.  Seleccione API Key

   ii.  Proporcione un nombre para el perfil de autorización.

   iii.  Guarde el perfil de autorización.

 5.  Haga clic en Habilitar.

 </container>

**¿Qué se puede lograr integrando Calendly con la plataforma Kore.ai XO?**

 La plataforma Kore.ai XO admite todas las acciones comunes en Calendly con plantillas de diálogo preconstruidas listas para usar.

**Plantillas compatibles**

| Acción           | Descripción            |
|------------------|------------------------|
|Get User     |Recuperar una cuenta de usuario|
|Get Event     |Recupera y proporciona información sobre eventos programados.|
|Get Event Invitees     |Recupera información sobre los asistentes de un evento programado.|
|Get Event Types     |Recupera y lista las categorías de eventos disponibles.|
|List Events     |Muestra una lista de todos los eventos programados.|

</container>
