**Descripción general**

La plataforma Kore.ai XO le permite integrarse con Sharepoint y le permite mostrar información del sitio de Sharepoint y la lista de elementos en Sharepoint.


</container>

<container>

**Autorización**

Para conectarse a Sharepoint, Kore.ai utiliza autenticación básica. El usuario final puede usar credenciales preautorizadas proporcionadas por el desarrollador durante el proceso de configuración o su propio perfil de autorización durante el proceso de configuración para permitir que el usuario final autorice durante la conversación.


 |Tipo de autorización                    | Basic |
 |----------------------------------------|-------|
 |Preautorizar la integración             |  Sí   |
 |Permitir a los usuarios autorizar la integración|  Sí   |


**Preautorizar la integración**

 Para facilitar el proceso de integración a los clientes, puede preautorizarla proporcionando las credenciales de autorización necesarias para obtener el token de acceso.

**Basic**

1. Por determinar

**Permitir a los usuarios autorizar la integración**

Este método requiere que el usuario final proporcione credenciales durante la conversación para la autorización.

**Basic**

1. Seleccione All Users to Authorize the Integration.

2. Haga clic en Select Authorization.

3. Seleccione Create New.

4. Seleccione el tipo de mecanismo de autorización.

   i.  Seleccione API Key

   ii.  Proporcione un nombre para el perfil de autorización.

   iii.  Guarde el perfil de autorización.

 5.  Haga clic en Enable.

 </container>

 <container>

**¿Qué se puede lograr integrando Sharepoint con la plataforma Kore.ai XO?**

 La plataforma Kore.ai XO admite todas las acciones comunes en Sharepoint con plantillas de diálogo predefinidas listas para usar.

**Plantillas admitidas**

| Acción           | Descripción            |
|------------------|------------------------|
|Obtener elementos de lista de Sharepoint     |Recupera y proporciona información sobre los elementos en una lista de SharePoint.|
|Obtener información del sitio de Sharepoint     |Recupera información sobre los elementos en un sitio de SharePoint|

</container>
