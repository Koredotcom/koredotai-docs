La plataforma Kore.ai XO admite la integración con el sistema de agentes Nice inContact para transferir las conversaciones sin necesidad de utilizar el BotKit.

Visite Deploy → Channels → Nice inContact → Configurations para gestionar Nice inContact.

Después de haber establecido exitosamente una conexión con Nice inContact, la plataforma Kore.ai XO mueve el sistema de agentes Nice inContact al estado configurado. No se requiere configuración adicional.

</container>
