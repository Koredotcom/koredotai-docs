Kore.ai XO Platform ahora admite la integración con el sistema de agentes de Helpshift para transferir las conversaciones sin necesidad de utilizar el BotKit.

<base target="_blank">
<container>

**Paso 1: Configurar el dominio de Helpshift**

1. Para configurar Helpshift como sistema de agentes, necesitará un dominio de Helpshift. Para obtener el dominio, siga las instrucciones en https://developers.helpshift.com/rest-api/getting-started/.

2. Pegue este dominio en el campo Domain en la pestaña de configuración.

</container>

<container>

**Paso 2: Obtener el Platform ID**

1. Para obtener el Platform ID, inicie sesión en https://developers.helpshift.com/ y vaya a Settings-> Integrations-> Platform ID

2. Pegue el Platform ID en el campo Platform ID en la pestaña de configuración.

</container>

<container>

**Paso 3: Obtener la API Key predeterminada**

1. Puede obtener la API Key predeterminada desde la sección API del panel de Helpshift.

2. Pegue la API Key en el campo API Key en la pestaña de configuración.

3. Habilite Helpshift haciendo clic en el botón 'Save' en Kore.ai XO Platform.

</container>
