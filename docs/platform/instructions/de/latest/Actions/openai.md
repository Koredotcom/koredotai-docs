**Descripción general**

Conecte OpenAI para generar respuestas y extraer habilidades para realizar diversas acciones.

La plataforma Kore.ai XO le permite integrarse con OpenAI, lo que le permite conectar fácilmente su instancia de OpenAI para extraer habilidades y generar respuestas según sea necesario.

</container>

<container>

**Autorización**

Para conectarse a OpenAI, Kore.ai utiliza autenticación básica. El usuario puede utilizar credenciales preautorizadas proporcionadas por el desarrollador durante el proceso de configuración. [Más información.](https://platform.openai.com/docs/api-reference)


 Para facilitar el proceso de integración a los clientes, puede preautorizarla proporcionando las credenciales de autorización necesarias para obtener el token de acceso.

**Básica**

1. Proporcione la API Key para autorizar la integración.
2. Siga los pasos a continuación para obtener los detalles requeridos de su instancia de OpenAI.

   a. Para obtener los detalles requeridos, navegue a [https://beta.openai.com/](https://beta.openai.com/)

      i.   Navegue a la sección de perfil.

      ii.  Haga clic en View API Keys.

      iii. Navegue a User → API Keys.

           1. Haga clic en Create new secret key.

           2. Copie la API Key.

           3. Pegue la API key en el campo API key de la plataforma Kore.ai XO.

 3. Haga clic en Habilitar.

 </container>

**¿Qué se puede lograr integrando OpenAI con la plataforma Kore.ai XO?**

 La plataforma Kore.ai XO admite todas las acciones comunes en OpenAI con plantillas de diálogo preconstruidas listas para usar.

**Plantillas compatibles**

| Acción           | Descripción            |
|------------------|------------------------|
|Extraer habilidades    |Identificar y extraer habilidades o capacidades específicas de los datos de entrada|
|Generar respuesta   |Generar respuestas o contestaciones basadas en la entrada|

</container>
