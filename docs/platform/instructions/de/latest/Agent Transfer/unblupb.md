<container>

La plataforma Kore.ai XO admite la integración con el sistema de agentes Unblu para transferir las conversaciones sin necesidad de utilizar el BotKit.

Visite Deploy → Channels → Unblu → Configurations para gestionar Unblu.

Después de haber establecido exitosamente una conexión con Unblu, la plataforma Kore.ai XO mueve el sistema de agentes Unblu al estado configurado. No se requiere configuración adicional.

</container>
