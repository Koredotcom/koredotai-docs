La plataforma Kore.ai XO admite la integración con el sistema de agentes Zendesk para transferir las conversaciones sin necesidad de utilizar el BotKit.

Visite Deploy → Channels → Sunshine Conversations → Configurations para gestionar Sunshine Conversations.

Después de haber establecido exitosamente una conexión con Zendesk Switchboard, la plataforma Kore.ai XO mueve el sistema de agentes Zendesk al estado configurado. No se requiere configuración adicional.

</container>
