La plataforma Kore.ai XO admite la integración con el sistema de agentes Zoom Contact Center para transferir las conversaciones sin necesidad de utilizar el BotKit.

Visite Deploy → Channels → Zoom Contact Center → Configurations para gestionar Zoom Contact Center.

Después de haber establecido exitosamente una conexión con Zoom Contact Center, la plataforma Kore.ai XO mueve el sistema de agentes Zoom Contact Center al estado configurado. No se requiere configuración adicional.

</container>
