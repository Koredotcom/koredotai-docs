**Descripción general**

Integre Google Gemini con la plataforma Kore.ai XO para desbloquear capacidades generativas avanzadas. Esta integración le permite aprovechar el poder de Gemini para automatizar la generación de contenido complejo, extraer información procesable y ofrecer respuestas más inteligentes y contextuales directamente dentro de sus asistentes de IA.


</container>

<container>

**Autorización**

Para conectarse a Google Gemini, Kore.ai utiliza autenticación mediante API Key. El usuario puede usar credenciales preautorizadas proporcionadas por el desarrollador durante el proceso de configuración. [Más información](https://ai.google.dev/api)

Para facilitar el proceso de integración a los clientes, puede preautorizarlo proporcionando las credenciales de autorización necesarias para obtener el token de acceso.

**Basic**

1. Proporcione la API Key para autorizar la integración.
2. Siga los pasos a continuación para obtener los detalles requeridos de su instancia de Google Gemini a través de Google AI Studio.

   a. Para obtener los detalles requeridos, navegue a [https://aistudio.google.com/](https://aistudio.google.com/)

    i.   Inicie sesión con su cuenta de Google.

    ii.  Haga clic en Get API key en la barra lateral izquierda.

    iii. Navegue a la sección API Keys.

    iv. Haga clic en Create API key.

    v. Seleccione Create API key in new project (o un proyecto existente si lo prefiere).

    vi. Copie la API Key generada.

    vii. Pegue la API key en el campo API Key de la plataforma Kore.ai XO.

 4. Haga clic en Habilitar.
